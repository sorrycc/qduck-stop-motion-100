# 黄色表情：100 段动作与创意

新增 100 套，不包含原版。每套包含 6×6 分镜大图、36 张逐帧 PNG、3 秒无限循环 GIF、生成提示词与验收记录。

用户偏好：主要表现动作，带一点故事性。因此每套围绕一个主要动作，安排蓄力、运动、轻微转折和回弹，避免仅仅更换静态材质。角色保留黄色圆脸、三撮头毛、粗眉、黑眼睛和橙色元素。

使用内置 image_gen 生成，ImageMagick 拆帧，FFmpeg 合成，不使用 HyperFrames。原生尺寸记录在每套的 audit.json 中。

全部 100 个方案在 concepts.json。失败和未通过检查的项目不计入完成数。完成后从 index.html 浏览所有成品。
